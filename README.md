# CSE423: Computer Graphics Assignments

This repository contains Python and PyOpenGL implementations of various computer graphics assignments and projects completed for **CSE423: Computer Graphics**. The project files cover fundamental rendering algorithms, object transformations, interactive games, and user input handling using OpenGL primitives.

---

## 📌 Repository Contents

| File Name | Description |
| :--- | :--- |
| `Task1_HouseInRain.py` | 2D scene rendering demonstrating basic shape output and rain animation. |
| `Task2_box.py` | Interactive point/box rendering and transformation practice. |
| `Catch_the_Diamonds.py` | Interactive OpenGL game involving user controls, collision detection, and score tracking. |
| `Lab_Assignment02.py` | Implementation of Midpoint Line Algorithm / Midpoint Circle Algorithm. |
| `24101651_assignment_3.py` | Assignment submission covering advanced transformations and interactive features. |
| `CSE423_Assignment1.py` | Basic OpenGL setup and coordinate manipulation assignment. |
| `Hello_openGL.py` | Starter script for testing OpenGL window creation and rendering context. |
| `Lets_draw_sth.py` | Experimental practice script for drawing fundamental primitives. |

---

## 🛠 Tech Stack & Prerequisites

* **Language:** Python 3.x
* **Graphics Library:** PyOpenGL / PyOpenGL_accelerate
* **Window Management:** FreeGLUT (OpenGL Utility Toolkit)

### Installation

Install the required Python packages using `pip`:

```bash
pip install PyOpenGL PyOpenGL_accelerate

```

*(Note: On Windows, if FreeGLUT DLL errors occur, ensure GLUT binaries or the compiled wheel packages are properly configured in your Python environment.)*
